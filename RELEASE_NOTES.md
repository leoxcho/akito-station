# macOS 1.0.1 · build 2

Appearance → App Logo provides seven owner-supplied A/S variants. Selection persists, updates in-app branding, and changes the running Dock icon using NSApplication.applicationIconImage. Finder retains the packaged default icon. The installed bundle is never rewritten.

Emulator mappings, adapters, library storage, cover-art services, PRO and updates are unchanged. Packaging retains ad-hoc hardened-runtime signing; this release is not Developer ID signed or notarized.
